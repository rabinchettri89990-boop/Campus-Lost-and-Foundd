Campus Lost and Found Management System

The Campus Lost and Found Management System is a Java-based desktop application developed using Java Swing. It helps manage lost and found items within a college campus in a simple and organized way.

## How to Use

1. Open the application to access the Dashboard.
2. Select **Report Lost Item** to report a lost belonging.
3. Select **Report Found Item** to report an item you have found.
4. Open **All Items** to view, search, and filter reported items.
5. Use the Edit option to update item details.
6. Mark an item as **Recovered** when it is returned.
7. Delete reports when they are no longer needed.
8. Visit **Statistics** to view an overview of lost and found items.
